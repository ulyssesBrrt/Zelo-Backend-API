#  Zelo — API REST Backend

O **Zelo Backend** é a API RESTful responsável pela inteligência de negócios, controle de dados e integração do ecossistema **Zelo**. Ele gerencia usuários, rotinas de medicamentos, horários de alarmes, histórico de doses, eventos da agenda e alertas do sistema.

---

## ✨ Principais Funcionalidades

* 🔐 **Autenticação e Perfis:** Cadastro, login e gestão do perfil de saúde (tipo sanguíneo, alergias e vínculo com cuidador).
* 💊 **Medicamentos e Estoque:** Cadastro completo, controle de quantidade disponível e atualização de status.
* ⏰ **Alarmes e Histórico de Doses:** Agendamento flexível de horários e registro diário de doses tomadas ou ignoradas.
* 📅 **Agenda de Saúde:** Centralização e consulta de eventos e compromissos médicos por período.
* 🚨 **Módulo SOS:** Gerenciamento de contatos de emergência com cadastro automático do SAMU (192).
* 🔔 **Central de Notificações:** Emissão de alertas para estoque crítico e lembretes de rotina.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java 21
* **Framework:** Spring Boot (Web MVC, Data JPA, Validation)
* **Banco de Dados:** MySQL
* **Build Tool:** Maven
